# Synchra

Synchra is a privacy-preserving clearing and leverage layer for Arc, built for the stablecoin-native, agent-driven future of capital markets. It unifies cross-market portfolio margin, programmable yield, and encrypted execution so a single pool of USDC, EURC, USYC, and tokenized collateral can back positions in perpetuals, FX, RWAs, and autonomous strategy vaults at the same time.
