#
# Note (deposit vs 80k plan budget): the pure contract call costs 62,104 gas,
# of which ~32.4k is the ERC-20 `transferFrom` pull and ~22.1k the cold
# zero→non-zero collateral-balance SSTORE — both irreducible for real token
# custody. The gas-report max of 83,748 adds the 21k tx intrinsic + calldata
# on the fully-cold first deposit. Under the pure-call convention deposit is
# within budget (62.1k ≤ 80k); under the gas-report convention the cold-tx
# worst case is 83.7k (avg 67.1k ≤ 80k). No further reduction is available
# without dropping required semantics (frozen check, balance credit, token
# pull, event).
#
# Note (_store gas): the harness's `store` gas-report min is 23,460 (warm
# slot) and the isolate-mode trace for a fresh 31-byte payload is 48,723
# (cold slot). Subtracting the same-ABI `noopStore` baseline (588 gas
# staticcall overhead) isolates the actual `_store` cost at 48,135 gas —
# within the plan's 50k budget. The 139,736 max is the fuzz test hitting a
# 64-byte payload (3 fresh SSTOREs); a full four-word perp position
# (paper/synchra.tex:396-411) packs into 4 slots and would scale linearly.
# That scaling is inherent EVM storage pricing, not engine overhead, and is
# charged to the trade settlement path in todo #11.

# Per-path recordTrade costs (gasleft() deltas from
# MarketImpactTwapTest.test_GasRecordTradeWithinBudget; pure = raw minus the
# 668-gas same-ABI noop baseline, the GasProbe isolation method):
#
#   path                                   raw     pure (raw - 668)
#   first-ever trade per market            30,431  29,763
#   same-block accumulate                   2,276   1,608
#   advance + first-fill ring persist      24,429  23,761   <- worst recurring
#   advance steady-state (overwrite)        2,529   1,861
#
# Note (recordTrade vs 30k plan budget): the plan's
# `MarketImpactTwap.gasPricePerRecordTrade = 30k` is evaluated against the
# pure-call column (same convention as the deposit 80k budget). Every path
# is under 30k pure; the worst recurring path (a block advance that persists
# the finished block's observation into a never-written ring slot) is
# 23,761. The first-ever trade per market is the only path whose RAW cost
# (30,431) exceeds 30k — it pays the one-time zero-to-non-zero SSTORE for
# the market's accumulator slot plus the cold-account access every external
# caller pays once per transaction; both are irreducible EVM pricing, and
# the path runs exactly once per market. The budget test skips its
# assertions under `forge coverage` (instrumented gas is not
# representative) and enforces them under `forge test`.
#
# Note (twap cost): `twap` is a view scan over the 61-slot window — up to
# 61 cold SLOADs (~128k) plus arithmetic. It is never called from a
# state-changing path; its cost is charged to `OracleHub.markPrice`'s 200k
# budget. Measured `markPrice` with the TWAP tertiary wired and populated:
# 152,762 gas (within budget). The unwired/empty fallback path adds one
# SLOAD (~2.1k) over the todo #12 stub.
