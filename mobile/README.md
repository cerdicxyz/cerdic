## Cerdic Mobile

- pwa first
- react native

### Status

Both scaffolded, nothing real wired in yet — bootstrap only.

- `pwa/` — Vite + React + TS, `vite-plugin-pwa` configured with a minimal
  manifest (no icons yet). `bun install && bun run dev` / `bun run build`.
- `native/` — Expo (`blank-typescript` template). `npm install && npm run
  ios` / `npm run android` / `npm run web`.

The real Cerdic UI/logic isn't ported into either yet.
